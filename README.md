# ScalaLab

![Scala](https://img.shields.io/badge/Scala-DC322F?logo=scala&logoColor=white)

Учебная работа по Scala (КазНУ, 2021) — ответы на тест в файле [`ScalaTest.docx`](ScalaTest.docx).

## Темы
- Объект и класс: в чём разница
- Трейты (traits) и их особенности
- Case-классы для неизменяемых данных
- Коллекции: `List`, `map`, `filter`, `reverse`, `length`
